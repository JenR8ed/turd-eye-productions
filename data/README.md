# Data Directory

This folder holds runtime data generated by the scripts:

- `rights_log.csv` — created/updated by `scripts/rights_logger.py`
- `rights_log.md` — Markdown export of the rights log (`rights_logger.py export`)
- `costs.csv` — created/updated by `scripts/cost_tracker.py`
- `cost_summary.md` — Markdown financial summary (`cost_tracker.py summary --markdown`)

These files are intentionally not committed with sample data so each user starts clean. The scripts create them on first use, headers included.

Set `TEP_DATA_DIR` to point the scripts at a different directory (the test suite and CI use a temporary directory so they never touch real operational data).
