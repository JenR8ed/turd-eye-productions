# Data Directory

This folder holds runtime data generated by the scripts:

- `rights_log.csv` — created/updated by `scripts/rights_logger.py`
- `rights_log.md` — Markdown export of the rights log
- `costs.csv` — created/updated by `scripts/cost_tracker.py`

These files are intentionally not committed with sample data so each user starts clean. The scripts will create them on first use.
