# 02 — Core Workflow

## Standard Pipeline

1. **Generate** on a paid commercial-rights plan (Suno Pro recommended for full songs).
2. **Edit** — cut weak sections, arrange structure, light mix (Audacity or Reaper).
3. **Log rights** using `templates/rights-log.md`.
4. **Distribute** via DistroKid with accurate AI disclosure.
5. **Monetize** — prioritize custom commissions while the catalog grows.

## Decision Points

- Fast cash needed? → Go straight to custom commissions (`docs/06-custom-commissions.md`).
- Building long-term assets? → Consistent niche catalog + YouTube visuals.
- Client work? → Prefer lower legal-risk tools (Soundraw / ElevenLabs / Stable Audio).

## Always Do
- Confirm commercial rights before generating.
- Add some human contribution.
- Disclose AI use.
- Keep the rights log current.
