# 01 — Quickstart (Get to First Dollar)

## Goal
Reach positive cash flow as fast as possible with minimal risk.

## Day 1–3 Actions

1. **Subscribe**
   - Suno Pro ($10/mo) → commercial rights for full songs
   - Optional: Soundraw Creator if you want low-risk instrumentals

2. **Generate 10–15 sample tracks**
   - Focus on 1–2 niches (e.g. lo-fi study, sleep/ambient, podcast beds, cinematic)
   - Save generation date + plan status

3. **Light edit the best 5–8**
   - Use Audacity (free)
   - Cut weak sections, normalize, export clean WAV/MP3

4. **Create your offer**
   - Use `templates/fiverr-gig.md`
   - Price starter packages at $75–150

5. **Distribute**
   - Upload edited tracks via DistroKid
   - Disclose AI use accurately

6. **List the gig**
   - Fiverr / Upwork / own site
   - Use samples as portfolio

## Success Metric
First paid custom order within 7–14 days of listing.
